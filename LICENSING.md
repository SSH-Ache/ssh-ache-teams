## Why it's public

Publishing the source is how you verify the security claims rather than taking them on trust —
particularly the zero-knowledge model, where the point is that the server *cannot* read your
secrets. That argument only works if you can check it. Public source is not the same as a free-for-
commercial-use grant, and nothing here waives the terms above.

## The community edition is different

[SSH-Ache/ssh-ache](https://github.com/SSH-Ache/ssh-ache) is a genuinely open-source, **Apache-2.0**
build for individual use — free to use, fork, and ship, **including commercially**, with no
permission needed. It has no team or server code at all. If you want a permissively licensed SSH
client, that's the one.
